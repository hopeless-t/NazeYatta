# NazeYatta

**やる前と、やった後を、迷わず確認。**

NazeYatta は、毎日の作業確認をシンプルにする小さなアプリです。

1. やることを書く
2. 今見るべきところを確認する
3. 終わったら結果を残す

難しい設定や専門用語を覚える必要はありません。

## Preview

`index.html` をブラウザで開くと、そのまま試せます。

- Light / Dark theme
- モバイル対応
- キーボード操作
- このブラウザだけに残る確認履歴
- 「できた / 気になる / まだ分からない」の3つの結果

データはこの静的 preview から外部へ送信しません。
